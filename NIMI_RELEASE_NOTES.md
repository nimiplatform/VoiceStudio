# VoiceStudio 0.5.9 for Nimi

Windows x86_64 edition using published Nimi SDK 0.21 and Kit/native 0.19.3.

- Create and reuse voice profiles, transcribe audio, dub video and produce audiobooks through Nimi-managed AI resources.
- Preserve complete voice descriptions and saved instructions across creation and restoration.
- Prepare canonical audio for separation while preserving source media and original timing.
- Retain existing voices, projects and recordings in VoiceStudio's business storage.
- Supply the portable release notes required for Registry admission. Version 0.5.8 remains immutable; it lacked this information field.

Windows typechecks, 542 Electron tests, 563 business tests, the installed-scheme protocol regression and 30 native bridge tests passed before this metadata correction. Fresh packaged business/Catalog acceptance is pending; earlier development acceptance is documented separately in README.md. macOS/Linux are not declared release targets. Retired Qwen voice-design models are not a supported creation path; existing voice assets are retained.
